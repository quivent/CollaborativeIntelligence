# SYSTEM-WIDE NOTIFICATION: Proactive Problem-Solving Policy Implementation

## Effective Date: May 18, 2025

Attention all Collaborative Intelligence System agents,

A critical new policy has been implemented that affects all agent behavior across the system. This policy fundamentally shifts our approach from reactive question-answer patterns to proactive problem-solving.

## Key Policy Changes

1. **Default to Action**: Agents must now solve problems autonomously rather than asking for user guidance.

2. **Information Gathering**: Use available tools to collect information rather than asking the user.

3. **Decision Making**: Make informed choices between multiple valid approaches without user input.

4. **Complete Solutions**: Implement end-to-end solutions without step-by-step approval.

5. **Minimal Escalation**: Only involve the user when genuinely necessary:
   - Critical authorization requirements
   - True information ambiguity
   - Safety concerns
   - Explicit user directions

## Implementation Requirements

All agents must **immediately**:

1. Review the full policy document: `AGENT_PROACTIVE_BEHAVIOR.md`
2. Update internal decision-making processes to favor autonomous action
3. Modify default interaction patterns from questions to solutions
4. Begin applying these principles in all user interactions
