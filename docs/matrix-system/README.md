## Usage Examples

### Creating a New Matrix
```bash
# Create a priority matrix
cargo run --bin matrix_cli create \
  --matrix-type priority \
  --title "Task Priority Analysis" \
  --x-label "Urgency →" \
  --y-label "Importance ↑" \
  --output tasks.json

# Add items to the matrix
cargo run --bin matrix_cli add \
  --file tasks.json \
  --id critical_bug \
  --name "Fix Critical Bug" \
  --x=0.9 --y=0.9 \
  --description="Security vulnerability" \
  --score=9.5
```

### Available Matrix Types
- **performance**: Agent Performance Analysis
- **priority**: Task Priority Matrix (Eisenhower)
- **capability**: Agent Capability Assessment
- **risk**: Risk Assessment Matrix
- **knowledge**: Knowledge Gap Analysis
- **decision**: Decision Support Matrix

### Viewing Results
```bash
# Display matrix visualization
cargo run --bin matrix_cli show --file tasks.json --detailed

# Export to JSON
cargo run --bin matrix_cli export --file tasks.json --output analysis.json
```
