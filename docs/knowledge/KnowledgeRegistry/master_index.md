# Knowledge Registry Master Index

## Purpose

This document serves as the master index for all globally distributed knowledge within the Collaborative Intelligence system. It provides a centralized reference point for accessing knowledge artifacts across the repository.

## Index Structure

Each entry in this index includes:
- **Document**: Name and short description
- **Location**: Path to the document
- **Category**: Type of content (architecture, protocol, optimization, etc.)
- **Keywords**: Important search terms
- **Last Updated**: Date of last update

## How to Use This Index

1. **Browse by Category**: Navigate to the relevant section for your area of interest
2. **Search by Keyword**: Use your editor's search function to find documents by keyword
3. **Access by Path**: Copy the document path to access it directly

## Maintaining This Index

The Knowledge Registry is maintained by the Knowledge Distribution Architecture. New documents are automatically added to this index when they are distributed. Manual updates to this index should be avoided - instead, use the Knowledge Distribution workflow to ensure proper cataloging.
