# Knowledge Registry Search Guide

## How to Find Information

The Knowledge Registry provides multiple ways to find information:

1. **Master Index** - For a complete catalog of all distributed knowledge
   - File: `/KnowledgeRegistry/master_index.md`

2. **Category Indices** - For domain-specific searches
   - Protocols: `/KnowledgeRegistry/category_indices/protocols.md`
   - Optimizations: `/KnowledgeRegistry/category_indices/optimizations.md`

3. **Distribution Log** - To track knowledge flow from agent sessions to global repositories
   - File: `/KnowledgeRegistry/distribution_log.md`

## Search By Topic

### Protocols and Compliance
- Protocol documentation, compliance requirements, enforcement mechanisms
- See `/KnowledgeRegistry/category_indices/protocols.md`

### System Optimizations
- Performance improvements, resource usage optimization, efficiency enhancements
- See `/KnowledgeRegistry/category_indices/optimizations.md`

## Recent Additions

The most recently added documents can be found in the Distribution Log:
- `/KnowledgeRegistry/distribution_log.md`

## Where to Go for Help

If you can't find what you're looking for:

1. Check the master index first
2. Look through relevant category indices
3. Consult the distribution log for recent additions
4. Ask Architect or Knowledge Administrator for assistance
