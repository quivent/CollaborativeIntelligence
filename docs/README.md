# Documentation

This directory contains comprehensive documentation for the Collaborative Intelligence system, organized hierarchically by topic.

## Directory Structure

- **core-concepts/** - Fundamental principles and conceptual framework
  - System philosophy
  - Core components
  - Design principles

- **system-design/** - System architecture and design documentation
  - Memory architecture
  - Learning systems
  - Knowledge management

- **agent-system/** - Agent ecosystem and interactions
  - Agent index and categorization
  - Inter-agent protocols
  - Agent creation standards

- **guides/** - User guides and tutorials
  - Getting started
  - Usage examples
  - Best practices

- **protocols/** - Communication and interaction standards
  - Protocol references
  - Communication formats
  - Standard implementations

- **development/** - Development guidelines and standards
  - Coding standards
  - Testing practices
  - Implementation guidelines

- **integration/** - System integration guidance
  - Integration patterns
  - External systems
  - API documentation

- **configuration/** - System configuration
  - CLAUDE.md specifications
  - Environment setup
  - Installation guides

## Documentation Format Standards

All documentation follows these standards:

1. **Titles**: Each document begins with a single H1 title
2. **Sections**: Organized with H2 and H3 headings in hierarchical order
3. **Lists**: Bulleted for unordered items, numbered for sequential steps
4. **Code**: Fenced code blocks with language specification
5. **Tables**: Used for structured comparisons and references
6. **Links**: Relative links to other documentation files
