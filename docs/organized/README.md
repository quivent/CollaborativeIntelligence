## 🔧 Documentation Standards

### Required Headers
All documents must include:
```markdown
# Document Title
**Type**: [Specification|Guide|Analysis|Deliverable|Process|Reference|Template]
**Status**: [Draft|Review|Approved|Active|Archived]
**Last Updated**: YYYY-MM-DD
**Owner**: [Team/Role responsible]
```

### Naming Conventions
- **Files**: lowercase-with-hyphens.md
- **Directories**: singular nouns, clear functional purpose
- **Suffixes**: -spec.md, -guide.md, -analysis.md, -template.md

### Quality Standards
- **Technical Accuracy**: All technical information verified and current
- **Clarity**: Accessible to both human users and agent systems
- **Completeness**: Comprehensive coverage within declared scope
- **Evolution-Ready**: Designed to grow with system capabilities
