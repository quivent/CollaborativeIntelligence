# CLI Documentation

This directory contains documentation related to the Command Line Interfaces (CLIs) of the Collaborative Intelligence project.

## Contents

- [Usage Guide](./usage.md) - Guide on how to use the CLI tools
- [Migration Guide](./migration.md) - Guide on migrating between different CLI versions
- [External CI Architecture](./external-ci-architecture.md) - Architectural analysis and dependency model for the external CI utility

## CLI Tools

- **CI** - Main Collaborative Intelligence CLI
- **TL** - Terminal Launcher CLI
- **Memory CLI** - Memory management CLI
- **Knowledge CLI** - Knowledge management CLI

## Overview

The Collaborative Intelligence system provides several command-line interfaces for interacting with the system. These tools enable agent activation, memory management, knowledge search, and system configuration.
