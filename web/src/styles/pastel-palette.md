## Usage Guidelines

1. **Cards & Panels**: Use light backgrounds (`-50`) with medium borders (`-200`)
2. **Text**: Use medium to dark colors (`-700`, `-800`) for readability
3. **Accents**: Use medium colors (`-600`, `-700`) for icons and highlights
4. **Hover States**: Transition from light to medium (`-50` to `-100`)
5. **Buttons**: Use gradients for primary actions, solid pastels for secondary

## Color Assignments by Component Type

- **Stats/Metrics**: Blue, Purple, Teal, Violet
- **Actions/Buttons**: Pink, Orange, Green
- **Information**: Blue, Violet, Teal
- **Success/Positive**: Green, Mint
- **Creative/Design**: Pink, Purple, Violet
- **Technical**: Blue, Teal
- **Warnings**: Yellow, Orange (keep soft)

**REMEMBER**: Always use the SOFT, LIGHT versions of these colors. No harsh, saturated colors!
