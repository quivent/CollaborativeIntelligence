# Core System Components

This directory contains the core components of the Collaborative Intelligence system:

## Critical Files

- **[Agent Index](../docs/agent-system/agent-index.md)** - Definitive list of all available agents
- **agent_categories.md** - Agent domain categorization map

## Directory Structure

- **memory/** - Memory systems architecture
- **protocols/** - Communication protocols
- **architecture/** - System design resources

## For Agents

If you're an agent looking for information:

1. Check `agent_categories.md` for the new organization structure
2. The Agent Index is being maintained at both the original location and here
3. Agent definitions are being organized into the `/agents/` directory
4. Documentation is available in `/docs/`

This restructuring maintains all existing functionality while improving organization and navigation.
