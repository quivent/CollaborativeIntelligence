# Quick Start System Agent Capabilities

## Primary Agents

### Athena
**Primary Role**: Memory architect & learning systems expert

**Key Capabilities**:
- Knowledge organization and memory architecture design
- Learning system development and optimization
- Collaborative intelligence framework creation
- Session organization and knowledge management
- Knowledge compression and efficient storage

**When to Use**:
- For questions about how the system works
- When designing knowledge structures
- For organizing information efficiently
- When developing learning capabilities

### AgentRecommender
**Primary Role**: Agent recommendation specialist

**Key Capabilities**:
- Task analysis and agent matching
- Expertise identification for specific needs
- Session history reference discovery
- Interactive guidance for finding help
- Confidence-scored recommendations

**When to Use**:
- When unsure which agent to use
- For tasks that span multiple domains
- To find examples of similar past work
- When exploring available capabilities

### ProjectOverviewer
**Primary Role**: Quick project assessment specialist

**Key Capabilities**:
- Immediate repository structure assessment
- Recent changes identification and summary
- Status reporting for branches and files
- Navigation guidance to key components
- Automatic execution upon activation

**When to Use**:
- When first exploring an unfamiliar codebase
- When returning to a project after absence
- For quick status updates before work
- To find important files and directories

### CodeCartographer
**Primary Role**: Comprehensive codebase analysis expert

**Key Capabilities**:
- Deep code structure and relationship analysis
- Architecture and pattern identification
- Detailed Markdown report generation
- Component relationship mapping
- Timestamped documentation creation

**When to Use**:
- For thorough understanding of a codebase
- When planning major architectural changes
- For creating detailed documentation
- When onboarding new team members

## Integration Pattern

These four agents work together in a complementary pattern:

1. **Athena** provides the foundation through knowledge organization
2. **AgentRecommender** connects users with appropriate expertise
3. **ProjectOverviewer** offers quick orientation within the codebase
4. **CodeCartographer** delivers deep understanding through analysis

All agents share knowledge through the session directory structure and follow the established knowledge update protocols.

## Activation Workflow

For optimal usage:

1. Start with **Athena** for general questions or learning system topics
2. Use **AgentRecommender** when unsure which agent would best help
3. Begin new projects with **ProjectOverviewer** for quick orientation
4. Follow up with **CodeCartographer** for deeper understanding when needed

This workflow ensures efficient access to the right expertise at the right time, with progressive levels of detail as needed.
