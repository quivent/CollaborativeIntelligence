## Resource Allocation Priorities

The team prioritizes resource allocation based on the following criteria:

1. **Strategic Partnerships**: Long-term clients with established relationships
2. **Project Type Alignment**: Projects matching core team capabilities
3. **Schedule Flexibility**: Projects with adaptable timelines
4. **Team Development**: Projects that expand team capabilities
5. **Utilization Optimization**: Projects that balance workload across the team

## Booking Procedures

### Standard Booking Process
1. Submit resource request through Resourcer Agent
2. Receive preliminary availability assessment (24-48 hours)
3. Confirm project requirements and timeline
4. Receive team allocation proposal
5. Approve and finalize resource commitment
6. Complete project onboarding process

### Expedited Booking
For urgent requirements, an expedited booking process is available:
1. Submit request with "PRIORITY" designation
2. Receive same-day preliminary assessment
3. Participate in resource planning session
4. Confirm commitment within 24 hours
5. Begin accelerated onboarding
