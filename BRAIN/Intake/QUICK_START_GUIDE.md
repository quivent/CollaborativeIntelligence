# BRAIN Curator Interface - Quick Start Guide
**Get the knowledge curation system operational in 15 minutes**

## For Agents: How to Submit Knowledge

### The Essentials
1. **Location**: `/BRAIN/Intake/` - the ONLY location to remember
2. **Process**: Pick template → Create file → Fill out → Submit
3. **Naming**: `[your-name]-[HH-MM].md` in today's date folder
4. **Time**: 2-3 minutes for standard submission

### Quick Example
```
1. Learn something valuable during your session
2. Go to: BRAIN/Intake/Templates/standard-submission.md
3. Copy template to: BRAIN/Intake/Submissions/2025-08-22/Debugger-14-30.md
4. Fill out the template with your knowledge
5. Save and forget - curator handles the rest
```

### What Gets Good Results
- **Specific examples** instead of general concepts
- **Clear context** about when to apply this knowledge  
- **Actionable insights** other agents can immediately use
- **Concrete problems solved** with your approach

## For Curators: Processing Workflow

### Daily Processing Routine
1. **Check Intake**: Scan `Submissions/[today]/` for new files
2. **Trinity Review**: Evaluate with Shannon, Architect, Memory perspectives
3. **Make Decisions**: Approve for integration or provide improvement feedback
4. **Integrate/Feedback**: Add to BRAIN or guide agent improvements
5. **Notify Agents**: Send encouraging notifications about their submissions

### Trinity Evaluation Questions
**Shannon**: Does this add new information efficiently?
**Architect**: Where does this fit in BRAIN structure?  
**Memory**: How does this connect with existing knowledge?

### Decision Framework
- **High scores from all three**: Auto-approve for integration
- **Mixed scores**: Manual review required
- **Low scores**: Improvement feedback needed

## Common Issues and Solutions

### Agents Not Submitting
**Problem**: Low participation in knowledge sharing
**Solution**: Send encouraging reminders highlighting value of contributions

### Poor Submission Quality
**Problem**: Vague or unhelpful submissions
**Solution**: Provide specific examples of excellent submissions in feedback

### Processing Bottlenecks  
**Problem**: Too many submissions, not enough processing capacity
**Solution**: Prioritize highest-value submissions, batch process similar items

### BRAIN Integration Conflicts
**Problem**: New knowledge doesn't fit cleanly with existing structure
**Solution**: Architect consultation for structural modifications

## Emergency Protocols

### Critical Knowledge Submissions
Use `priority-submission.md` template for:
- Security vulnerabilities
- System-breaking discoveries  
- Major capability breakthroughs
- Time-sensitive opportunities

Process within 2-4 hours maximum.

### System Problems
- **File corruption**: Restore from templates
- **Processing overflow**: Triage by submission quality
- **Agent confusion**: Provide immediate guidance
- **Integration errors**: Architect consultation required
