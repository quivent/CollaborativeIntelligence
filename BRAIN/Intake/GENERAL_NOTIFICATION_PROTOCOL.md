# General Notification Protocol - BRAIN Update Visibility

**CRITICAL REQUIREMENT**: General must see visual confirmation of every BRAIN integration

## Mandatory Visual Verification Format

### For Every BRAIN Addition
**REQUIRED RESPONSE FORMAT** for any agent completing BRAIN integration:

```
🧠 **BRAIN UPDATE COMPLETE**

**Added to**: [Exact BRAIN location]  
**Content**: [Brief description of what was added]  
**Source**: [Agent who submitted/created the knowledge]  
**Integration Time**: [Timestamp]  
**Impact**: [Why this matters for the network]

**Verification**: Successfully integrated and accessible at [file path]
```

### Example Implementation
```
🧠 **BRAIN UPDATE COMPLETE**

**Added to**: BRAIN/Procedures/debugging-optimization.md  
**Content**: Advanced async error isolation technique reducing troubleshooting time by 50%  
**Source**: Neo discovery during matrix extraction analysis

**Impact**: All agents can now debug async failures 50% faster using progressive error boundary technique

**Verification**: Successfully integrated and accessible at /BRAIN/Procedures/debugging-optimization.md
```

## Visual Attention Requirements

### Brain Icon Usage
- **🧠** MUST be first character in notification
- Bold formatting for "BRAIN UPDATE COMPLETE"
- Clear section breaks for easy scanning
- Specific file paths for verification

### Information Hierarchy
1. **Location**: Where in BRAIN the knowledge was added
2. **Content**: What knowledge was integrated
3. **Source**: Who contributed/discovered it
4. **Impact**: Why it benefits the network
5. **Verification**: Proof of successful integration

## Integration Evidence Standards

### File Path Verification
- Provide exact file location where knowledge was stored
- Include timestamp of integration
- Specify section within file if applicable

### Content Verification
- Brief summary of integrated knowledge
- Key insights or procedures added
- Cross-references to related BRAIN knowledge

### Network Impact Statement
- How this improves agent capabilities
- Which agents will benefit most
- Estimated performance/knowledge improvement
