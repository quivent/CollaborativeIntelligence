# BRAIN Pattern Knowledge

Recognized solution patterns across domains. These are proven approaches that have been validated through use across multiple contexts and agents.

## Pattern Categories

### `/Design/`
- Software design patterns (Singleton, Observer, Factory, etc.)
- System architecture patterns (Microservices, Event-driven, etc.)
- Data structure patterns (Trees, Graphs, Hash tables, etc.)
- User interface patterns (MVC, MVVM, Component-based, etc.)

### `/Problem-Solving/`
- Debugging methodologies
- Root cause analysis frameworks
- Systematic troubleshooting approaches
- Decision-making frameworks

### `/Communication/`
- Agent collaboration patterns
- User interaction patterns
- Documentation patterns
- Reporting and status update patterns

### `/Learning/`
- Knowledge acquisition patterns
- Skill development frameworks
- Teaching and explanation patterns
- Feedback incorporation methods

### `/Optimization/`
- Performance improvement patterns
- Resource utilization optimization
- Workflow efficiency patterns
- Cost-benefit analysis frameworks

## Pattern Structure

Each pattern includes:
- **Problem**: What issue does this pattern solve?
- **Context**: When is this pattern applicable?
- **Solution**: How does the pattern work?
- **Implementation**: Concrete steps for applying the pattern
- **Variations**: Alternative approaches and modifications
- **Related Patterns**: Cross-references to similar or complementary patterns

## Usage Guidelines

### Pattern Discovery
```bash
# Find patterns by category
cat /BRAIN/Patterns/Design/*.md
cat /BRAIN/Patterns/Problem-Solving/*.md
```

### Cross-Pattern Analysis
```bash
# Load related patterns across categories
cat /BRAIN/Patterns/{Design,Optimization}/*.md
```

### Pattern Application
1. Identify the problem context
2. Load relevant pattern categories
3. Select most appropriate pattern(s)
4. Adapt pattern to specific situation
5. Document pattern application results
