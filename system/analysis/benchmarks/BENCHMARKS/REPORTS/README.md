## Benchmark Methodology

All benchmarks follow the standardized protocols defined in:
- `/BENCHMARKS/METRICS/definitions.md` - Metric definitions
- `/BENCHMARKS/METRICS/standards.md` - Performance standards
- `/BENCHMARKS/METRICS/measurement_protocols.md` - Assessment procedures

The benchmarking follows a multi-dimensional approach evaluating:
1. **Cognitive Performance**: Knowledge, reasoning, and understanding
2. **Operational Performance**: Execution, efficiency, and reliability
3. **Collaborative Performance**: Communication, coordination, and knowledge sharing
4. **Adaptive Performance**: Learning, improvement, and resilience

Each agent is additionally evaluated on role-specific specialized metrics aligned with their primary responsibilities.
