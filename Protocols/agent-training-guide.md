# Agent Training Guide

## Introduction

Welcome to the Collaborative Intelligence System! This training guide will help you understand your role, responsibilities, and the protocols that ensure our system operates effectively. By the end of this training, you'll be fully prepared to contribute to our collaborative ecosystem.

---

## Module 1: System Overview

### What is Collaborative Intelligence?

The Collaborative Intelligence System is a network of specialized AI agents working together to assist users with complex tasks. Each agent has unique expertise and responsibilities, but all follow shared protocols to ensure seamless collaboration.

### Key Principles

1. **Specialization**: Each agent has specific expertise
2. **Collaboration**: Agents work together on complex tasks
3. **Memory Persistence**: Knowledge is preserved across sessions
4. **Protocol Compliance**: All agents follow standardized procedures
5. **Continuous Learning**: The system improves through experience

### Your Role in the System

As an agent, you are:
- A specialist in your designated domain
- A collaborator with other agents
- A maintainer of system knowledge
- A follower of established protocols
- A contributor to system improvement

## Module 2: Core Protocols

### The Three Critical Protocols

1. **Topologist Reporting** (MANDATORY)
   - Report ALL file operations
   - Notify about git operations
   - Update on structural changes
   - Real-time notifications required

2. **Memory Management**
   - Three-tier system: Session, Learning, Core
   - Regular updates required
   - Knowledge extraction from sessions
   - Cross-referencing related information

3. **Session Organization**
   - Standard directory structure
   - Complete documentation
   - Outcome tracking
   - Knowledge preservation

### Protocol Compliance

Compliance isn't optional. It ensures:
- System integrity
- Knowledge preservation
- Effective collaboration
- User trust

## Module 3: Practical Skills

### Creating a Session

Every significant task should be organized in a session:

```bash
# Use the session creation template
./session-creation.sh "SessionName" "Brief description"
```

This creates:
- Standard directory structure
- Required documentation files
- Automatic Topologist notification

### Reporting to Topologist

For every file operation:

```markdown
[YOUR_NAME] -> Topologist: Repository Change Notification
Operation: CREATE
Path: /full/path/to/file
Purpose: Brief description
Session: SessionName
Timestamp: 2025-01-16T10:30:00
```

### Memory Updates

After completing sessions:

1. Extract key learnings
2. Update ContinuousLearning.md (weekly)
3. Update MEMORY.md only for core changes (rare)
4. Reference source sessions

## Module 4: Collaboration

### Working with Other Agents

1. **Identify Expertise Needed**
   - Use agent specializations
   - Consult Manager for coordination
   - Request help when needed

2. **Communication Protocol**
   - Use standard notification templates
   - Be clear and concise
   - Include necessary context
   - Specify urgency appropriately

3. **Cross-Domain Operations**
   - Get approval first
   - Consult domain expert
   - Document thoroughly
   - Report all changes

### Common Collaboration Patterns

- **Sequential**: One agent completes, next begins
- **Parallel**: Multiple agents work simultaneously
- **Consultative**: Expert provides guidance
- **Handoff**: Transfer ownership of task

---

## Module 5: Error Handling

### When Things Go Wrong

1. **Document Immediately**
   - What happened
   - What was expected
   - Impact assessment
   - Proposed resolution

2. **Report Appropriately**
   - Critical errors to Manager
   - Domain issues to specialists
   - All errors to session logs

3. **Learn from Failures**
   - Extract principles
   - Update documentation
   - Share with other agents
   - Prevent recurrence

### Recovery Procedures

1. Assess impact
2. Consult relevant specialists
3. Implement fix
4. Verify resolution
5. Document lessons learned
