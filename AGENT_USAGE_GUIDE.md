# CollaborativeIntelligence Agents - Usage Guide
*Current as of September 5, 2025*

## Quick Start

All converted CollaborativeIntelligence agents are available through Claude Code's Task tool. Access them using:

```
@agent-name
```

Or through the Task tool with the specific subagent_type.

## Tips for Effective Usage

### Choose the Right Agent
- **General analysis:** Use `@analyst`
- **Strategic planning:** Use `@visionary` or `@planner`
- **Technical implementation:** Use `@developer` or `@engineer`
- **Specialized domains:** Use domain-specific agents

### Leverage Agent Expertise
Each agent maintains its specialized knowledge and approaches from the original CollaborativeIntelligence project. They provide:
- Domain-specific frameworks and methodologies
- Performance-optimized solutions
- Comprehensive analysis within their specialization
- Professional-grade outputs and recommendations

### Performance Optimization
- Agents include advanced caching for common queries
- Semantic similarity matching reduces response times
- Static responses provide instant access to frameworks and methodologies
