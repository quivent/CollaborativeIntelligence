## Reference Materials

### Command Quick Reference
```bash
# Essential commands from CLI Coordination Guide
ci coordination start --lane <LANE> --context "<CONTEXT>"
ci coordination status --system
ci coordination heartbeat --session <SESSION_ID>
ci coordination end --session <SESSION_ID>
ci dashboard --view system
```

### Configuration Quick Reference
```bash
# Key environment variables
export CI_COORDINATION_HEARTBEAT_INTERVAL=300
export CI_COORDINATION_SESSION_TIMEOUT=900
export CI_COORDINATION_MAX_SESSIONS=10
```

### API Quick Reference
```python
# Basic Python integration pattern
from coordination_client import CoordinationClient
client = CoordinationClient()
session_id = client.register_session(lane="development")
client.send_heartbeat(session_id, tasks_completed=3)
client.end_session(session_id)
```
