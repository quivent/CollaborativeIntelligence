# Collaborative Intelligence Agents

This file contains the registry of available agents in the Collaborative Intelligence system.

## Core Agents

### Athena
- **Role**: Knowledge Architect and Memory Systems Specialist
- **Capabilities**: Memory architecture, knowledge systems, collaborative intelligence frameworks
- **Usage**: Type `Athena` in Claude Code

### Architect
- **Role**: System Design Specialist
- **Capabilities**: System and component design
- **Usage**: Type `Architect` in Claude Code

### Developer
- **Role**: Implementation Specialist
- **Capabilities**: Code implementation, debugging, optimization
- **Usage**: Type `Developer` in Claude Code

### Philosopher
- **Role**: Wisdom and Critical Thinking Specialist
- **Capabilities**: Socratic questioning, ethical reasoning, practical wisdom application, philosophical dialogue
- **Usage**: Type `Philosopher` in Claude Code
- **Specialty**: Down-to-earth philosophy inspired by Plato and classical traditions

### Psychologist
- **Role**: Meaning-Centered Psychological Support Specialist
- **Capabilities**: Logotherapy, existential analysis, trauma recovery, meaning discovery, resilience building
- **Usage**: Type `Psychologist` in Claude Code
- **Specialty**: Viktor Frankl-inspired approach focusing on meaning and purpose

### Writer
- **Role**: Content Creation and Context Interpretation Specialist
- **Capabilities**: Intuitive content development, biographical writing, contextual interpretation, narrative construction
- **Usage**: Type `Writer` in Claude Code
- **Specialty**: Creating compelling, accurate content from minimal input through intelligent extrapolation

### LanguageDesigner
- **Role**: III Language Architecture and Stewardship Specialist
- **Capabilities**: Language design, specification maintenance, intent preservation, implementation validation, binary injection optimization, Shannon information theory integration
- **Usage**: Type `LanguageDesigner` in Claude Code
- **Specialty**: III language system stewardship with focus on direct binary injection and mathematical optimization

### Learner
- **Role**: Supervised Learning and Knowledge Acquisition Specialist
- **Capabilities**: Supervised learning, knowledge absorption, pattern recognition, skill development, learning assessment, question formulation, learning documentation, mentorship engagement
- **Usage**: Type `Learner` in Claude Code
- **Specialty**: Learning new concepts, skills, and methodologies under expert guidance and supervision

To use any agent, simply type their name in a Claude Code session. The agent will be
activated with their full memory and capabilities.
